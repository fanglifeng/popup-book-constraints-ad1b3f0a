## 实现取舍

连续场景使用同一时间轴保持镜头、折页和道具同步。`preserve-3d` 保留嵌套透视，竖立纸片以底边为支点旋转。相同帧输入得到相同画面，可任意拖动与并行渲染。几何和插画是可编辑组件，只有音轨沿用参考素材。

本版本为 2.5D 重建；复杂折纸几何、投影和纸张颗粒以简化插画及 CSS 阴影近似。
